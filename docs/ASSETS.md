# Asset Ledger

Every file under `assets/` (sprites, UI, fonts, audio) must have a row here, because it ships inside the desktop packages and the web build's `.data` file. The Kiroween 2026 rules prohibit third-party copyrighted or trademarked material unless we have permission.

**Allowed:** original work by the team, CC0, or SIL OFL (fonts only).
**Not allowed:** ripped or traced game sprites, game or vendor fonts, vendor logos, or copyrighted music.
